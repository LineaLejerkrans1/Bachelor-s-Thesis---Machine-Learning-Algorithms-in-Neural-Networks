# Bachelor-s-Thesis---Machine-Learning-Algorithms-in-Neural-Networks
This project explores the mathematical principles and practical nuances of deep learning fundamentals. Built to analyze optimization landscapes, cost functions, hyperparameter tuning, and regularization techniques without relying on high-level deep learning frameworks.

* The core neural network implementation and base code structure for this project are adapted from **Michael Nielsen's** online book [*Neural Networks and Deep Learning*](http://neuralnetworksanddeeplearning.com/).
